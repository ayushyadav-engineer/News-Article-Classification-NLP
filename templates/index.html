About the Project

Why classify news automatically?

Every day, publishers and aggregators handle thousands of articles. Manually tagging each one by topic is slow and inconsistent. This project demonstrates how NLP and Machine Learning can automate that process reliably and instantly.

The Goal

Automatically predict whether a news article belongs to World, Sports, Business, or Sci/Tech — using only its text.

The Approach

Clean raw text with an NLP pipeline, convert it into numeric TF-IDF features, then classify it with a trained supervised ML model.

The Outcome

A lightweight, fully functional web app that shows the entire text-classification pipeline end-to-end — from raw text to prediction.

What is NLP?

Natural Language Processing, in plain terms

Natural Language Processing (NLP) is the branch of Artificial Intelligence that helps computers understand, interpret and work with human language — turning unstructured text into structured data a Machine Learning model can actually learn from.

  • Cleans messy, real-world text
  • Breaks sentences into meaningful tokens
  • Reduces words to their root/base form
  • Converts words into numeric vectors (TF-IDF)
preprocess.py 
def clean_text(text):
    text = text.lower()                     # 1. lowercase
    text = remove_punctuation(text)         # 2. punctuation
    text = remove_numbers(text)             # 3. numbers
    text = remove_special_characters(text)  # 4. special chars
    tokens = word_tokenize(text)            # 5. tokenize
    tokens = remove_stopwords(tokens)       # 6. stopwords
    tokens = lemmatize_tokens(tokens)       # 7. lemmatize
    return " ".join(tokens)              # 8. cleanup
